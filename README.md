# ZRep iPhone price cache

This repository contains only sanitized, public price snapshots used by the
ZRep and Phone-Parts “sell your iPhone” pages. It contains no customer data,
credentials, source-system configuration, or operational application code.

The snapshots are rebuilt automatically every night. A new snapshot is only
published after its model, storage, and condition-price structure has passed
validation; the previous valid snapshot remains available if refreshing fails.
